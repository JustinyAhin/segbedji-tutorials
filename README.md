# segbedji tutorials

Companion code for tutorials on [segbedji.com](https://segbedji.com).

- [`mcp-search`](mcp-search): [Adding an MCP server to an existing SvelteKit search app](https://segbedji.com/adding-an-mcp-server-to-my-search-app/)
- [`llm-eval-harness`](llm-eval-harness): [Benchmarking cheap LLMs before you switch models](https://segbedji.com/benchmarking-cheap-llms-before-you-switch-models/)

Each folder is a standalone project with its own README. Run `bun install` inside it.
